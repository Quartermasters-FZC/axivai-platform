# AXIVAI Design System — Brand Rules (v1, October 2026)

Canonical system: https://claude.ai/artifact/Pyf3uEkt6Kd7CCxZMtCWRY — tokens, vector logos, icons, fonts, 8 React components, full brand book. This note is the summary; the artifact wins if they differ.

## Supersedes
- Arial in the VNext whitepaper → Montserrat (headings, buttons, figures) + Inter (body, UI, data). Both SIL OFL.
- Warm Gray #E8E4DC as "secondary text" on the brand board → divider/surface only on light grounds (1.25:1 fails). Secondary text = `ink-muted` #57534E.

## Colour
- Brand: Obsidian #1C1917 · AXIVAI Gold #D4A017 · Cream White #FEFDFB · Warm Gray #E8E4DC.
- Gold is never text on light (2.3:1). Gold-toned text = `accent-ink` #8B6914 (5.0:1 on cream). Text on gold fill = obsidian (7.4:1).
- Status (provenance): verified #1F5F8B · estimate #8B6914 · risk #B13A1E · unknown = ink-muted. Always glyph + word.
- Signature gradient (A-mark/brand graphics only): obsidian → #7A5012 → #D4A017 → #EDB02A.
- Two themes: Cream (light) and Obsidian (dark); every text pair ≥4.5:1 in both.
- Print CMYK/Pantone: not yet specified.

## Logo
- Vector masters rebuilt from the supplied PNG (96% pixel match): primary, reverse, black, white wordmarks; gradient, reverse, gold, black A-marks; app icon.
- Clear space = ½ wordmark height. Minimum 20px tall on screen / 25mm print; below that use the A-mark.
- A's have no crossbar, carry the gradient; other letters solid obsidian (cream in reverse).

## Rules tied to the product
- Every number in TCO, research and chatbot carries a provenance tag: Verified / Estimate / Default / Unknown / Risk.
- Results using defaults or estimates open with an assumption notice naming them and the possible swing.
- Freshness: grant/price data >30 days and market data >90 days are tagged Risk.
- Unfavourable scenarios get equal visual weight; AXIVAI's scenario gets no highlight colour.
- All rendered/AI imagery carries a "Concept rendering" label until replaced by real pilot photography.
- Hero imagery shows mobile charging in action — never fixed pedestals under a permanent canopy.

## Voice
- Tagline: "Power anywhere. Ready when needed." (never reworded)
- Confident, specific, sourced; sentence case; no hype words, exclamation marks or emoji.
- Signature phrases: "electricity as physical cargo", "logistics-first, not construction-first", "bring the charger to the bus".
