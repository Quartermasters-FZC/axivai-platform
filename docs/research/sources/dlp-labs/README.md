# DLP Labs research archive

Research prepared under DLP Labs (now defunct). All rights belong to Aliff Group, which owns AXIVAI.

- `raw/` holds verbatim text pulls from Google Drive. It is git-ignored because the originals contain personal contact details, internal confidentiality markings and DLP Labs sales material.
- Cleaned, re-sourced versions for publication under AXIVAI branding go in `../processed/` (to be created) and follow the evidence standard in the concept paper (§11).

Each raw file starts with front matter: title, Drive id and link, MIME type, modified date, Drive folder path, pull date and flags.
